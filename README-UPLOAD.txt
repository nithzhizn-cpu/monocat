mono Кіт — готова версія для GitHub Pages
==========================================

Це вже зібрана статична версія гри. Node.js, npm і GitHub Actions не потрібні.

Як опублікувати:

1. Розпакуйте архів.
2. У репозиторії GitHub видаліть старі файли гри, щоб вони не конфліктували.
3. Завантажте ВМІСТ папки з архіву в корінь репозиторію:
   - index.html
   - favicon.svg
   - папку assets
   - .nojekyll
   - README-UPLOAD.txt
4. Відкрийте Settings → Pages.
5. У Build and deployment виберіть:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Натисніть Save і зачекайте 1–3 хвилини.
7. Відкрийте адресу, яку покаже GitHub Pages.

Якщо сторінка ще стара або порожня, оновіть її без кешу або відкрийте
в приватній вкладці після завершення нового deployment.
