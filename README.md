# mono Кіт — доставка переказу

Неофіційний концепт мобільної гри для monobank. Кіт має за 75 секунд
доставити переказ до Банки, зібрати монети й кешбек та уникнути фішингових
посилань, шахраїв і комісій.

## Можливості

- адаптивна версія для iPhone, Android і комп’ютера;
- сенсорний подвійний стрибок;
- 75-секундний забіг;
- монети, кешбек, антифішинг і турбо;
- перешкоди: фішинг, шахраї та комісії;
- життя, комбо, нагороди й секретні скіни;
- локальний рекорд і демо-рейтинг;
- звук без зовнішніх аудіофайлів;
- автоматична публікація на GitHub Pages.

## Локальний запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте в корінь репозиторію весь вміст цієї папки.
3. Перейдіть у `Settings → Pages`.
4. У полі `Source` виберіть `GitHub Actions`.
5. Відкрийте вкладку `Actions` і дочекайтеся завершення процесу
   `Deploy to GitHub Pages`.
6. Посилання на гру з’явиться у `Settings → Pages`.

Наступні зміни в гілці `main` публікуватимуться автоматично.

## Важливо

Це незалежний неофіційний концепт, не пов’язаний і не схвалений monobank.
Назва monobank та пов’язані позначення належать їхнім відповідним власникам.
Гра не здійснює реальних банківських операцій і не обробляє платіжні дані.
